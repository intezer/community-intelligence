## Posts

- [When Viruses Mutate: Did SunCrypt Ransomware Evolve from QNAPCrypt?](https://research.intezer.com/blog/2021/03/when-viruses-mutate-did-suncrypt-ransomware-evolve-from-qnapcrypt/) (2021-03-02): Code reuse links SunCrypt ransomware to QNAPCrypt, used against NAS devices in 2019, while dark web research shows the two are run by different actors.
- [PureLocker: New Ransomware-as-a-Service Being Used in Targeted Attacks Against Servers](https://research.intezer.com/blog/2019/11/purelocker-ransomware-being-used-in-targeted-attacks-against-servers/) (2019-11-12): PureLocker, ransomware written in PureBasic and used in targeted attacks on servers, shares code with the more_eggs backdoor sold by a MaaS provider.
- [How We Seized 15 Active Ransomware Campaigns Targeting Linux File Storage Servers](https://research.intezer.com/blog/2019/07/seizing-15-active-ransomware-campaigns-targeting-linux-file-storage-servers/) (2019-07-10): We simulated over 1,091 infections to exhaust QNAPCrypt’s static Bitcoin wallet list, temporarily halting 15 ransomware campaigns targeting QNAP NAS servers.
- [Yet Another Distraction? A New Version of North Korean Ransomware Hermes Has Emerged](https://research.intezer.com/blog/2018/02/another-distraction-new-version-north-korean-ransomware-hermes/) (2018-02-08): Hermes 2.1 ransomware shares code with the Hermes version used as a diversion in a Taiwan bank heist and thought to originate from North Korea’s Lazarus group.
- [NotPetya Returns as Bad Rabbit](https://research.intezer.com/blog/2017/10/notpetya-returns-bad-rabbit/) (2017-10-25): Bad Rabbit ransomware reuses NotPetya code: 27% of its fake Adobe Flash installer loader and 13% of its encryption module match NotPetya samples.
