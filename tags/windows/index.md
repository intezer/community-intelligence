## Posts

- [When Everything Becomes Open-Source](https://research.intezer.com/blog/2026/11/when-everything-becomes-open-source/) (2026-11-10): AI agents rebuilt maintainable source code for Slack, Apple’s Finder and the TinyTurla-NG backdoor from binaries alone. Compiled code no longer hides source.
- [Rubber Ducky in the Sky](https://research.intezer.com/blog/2026/09/rubber-ducky-in-the-sky/) (2026-09-01): A one-letter typo in a mouse setup address led to a “privacy browser” hiding a remote-control engine in a Microsoft-signed MSIX, part of a ten-year chain.
- [Two Trojan Families Trotting in Through Google Search Ads](https://research.intezer.com/blog/2026/07/two-trojan-families/) (2026-07-27): SilentMare, a downloader, and HollowMare, a browser-hijacking PUA, spread via trojanized PDF and file converter apps promoted through Google search ads.
- [There's Something About CryptBot: Yet Another Silly Stealer (YASS)](https://research.intezer.com/blog/2024/09/cryptbot-yet-another-silly-stealer-yass/) (2024-09-10): YASS, an infostealer labelled CryptBot but sharing little of its code, arrives via the MustardSandwich downloader and IDATLOADER and can drop NetSupport.
- [Dissecting SSLoad Malware: A Comprehensive Technical Analysis](https://research.intezer.com/blog/2024/06/ssload-technical-malware-analysis/) (2024-06-10): SSLoad’s chain from a phishing MSI to PhantomLoader, hidden in a patched 360 Total Security DLL, and a Rust downloader that reads its C2 from Telegram.
- [Operation HamsaUpdate: A Sophisticated Campaign Delivering Wipers Puts Israeli Infrastructure at Risk](https://research.intezer.com/blog/2023/12/stealth-wiper-israeli-infrastructure/) (2023-12-20): Phishing aimed at Israeli F5 users abused a real BIG-IP flaw to deliver new wipers, Hatef for Windows and Hamsa for Linux, plus the Handala AutoIt loader.
- [How Hackers Use Binary Padding to Outsmart Sandboxes and Infiltrate Your Systems](https://research.intezer.com/blog/2023/05/how-hackers-use-binary-padding-to-outsmart-sandboxes/) (2023-05-18): Binary padding inflates PE files with junk data to change hashes and beat sandbox size limits. PufferPhishing pads files that still compress by over 90%.
- [YTStealer Malware: "YouTube Cookies! Om Nom Nom Nom"](https://research.intezer.com/blog/2022/06/ytstealer-malware-youtube-cookies/) (2022-06-29): YTStealer steals only YouTube authentication cookies, using anti-analysis code from the Chacal project. Its build path names YouBot Solutions.
- [New Conversation Hijacking Campaign Delivering IcedID](https://research.intezer.com/blog/2022/03/conversation-hijacking-campaign-delivering-icedid/) (2022-03-28): An IcedID campaign hijacks email threads from compromised Exchange servers and delivers ISO files with LNK and DLL payloads to bypass Mark-of-the-Web.
- [New SysJoker Backdoor Targets Windows, Linux, and macOS](https://research.intezer.com/blog/2022/01/new-backdoor-sysjoker/) (2022-01-11): SysJoker is a multi-platform backdoor for Windows, macOS and Linux, found on a Linux web server at an educational institution. Analysis, IoCs and detections.
- [Vermilion Strike: Linux and Windows Re-implementation of Cobalt Strike](https://research.intezer.com/blog/2021/09/vermilionstrike-reimplementation-cobaltstrike/) (2021-09-13): Vermilion Strike is an undetected Linux re-implementation of Cobalt Strike Beacon, with matching Windows samples, used against telecom, government and finance.
- [How to Detect Cobalt Strike](https://research.intezer.com/blog/2021/08/cobalt-strike-detect-this-persistent-threat/) (2021-08-18): Cobalt Strike Beacon arrives via Office macros, supply chain attacks, living off the land and EXE files. How to detect each with static and dynamic analysis.
- [Klingon RAT Holding on for Dear Life](https://research.intezer.com/blog/2021/06/klingon-rat-holding-on-for-dear-life/) (2021-06-17): Klingon RAT is a Go remote access trojan with mostly unique code that kills antivirus processes, uses many persistence and UAC bypass methods and TLS C2.
- [Wrapping Up a Year of Infamous Bazar Campaigns](https://research.intezer.com/blog/2021/05/wrapping-up-a-year-of-infamous-bazar-campaigns/) (2021-05-27): A profile of Bazar, the backdoor attributed to the TrickBot gang and named for its EmerDNS .bazar C2 domains, and four prominent campaigns from its first year.
- [HabitsRAT Used to Target Linux and Windows Servers](https://research.intezer.com/blog/2021/04/habitsrat-used-to-target-linux-and-windows-servers/) (2021-04-20): HabitsRAT, a Go RAT first seen on hacked Microsoft Exchange servers, has an undetected Linux variant and runs only commands signed with the attacker’s key.
- [When Viruses Mutate: Did SunCrypt Ransomware Evolve from QNAPCrypt?](https://research.intezer.com/blog/2021/03/when-viruses-mutate-did-suncrypt-ransomware-evolve-from-qnapcrypt/) (2021-03-02): Code reuse links SunCrypt ransomware to QNAPCrypt, used against NAS devices in 2019, while dark web research shows the two are run by different actors.
- [A Storm is Brewing: IPStorm Now Has Linux Malware](https://research.intezer.com/blog/2020/10/a-storm-is-brewing-ipstorm-now-has-linux-malware/) (2020-10-01): IPStorm, a Golang botnet that hides traffic in the IPFS peer-to-peer network, now has Linux variants adding SSH brute forcing, Steam gaming fraud and ad fraud.
- [Fantastic payloads and where we find them](https://research.intezer.com/blog/2020/03/fantastic-payloads-and-where-we-find-them/) (2020-03-30): Emotet, Dridex, Ursnif and TrickBot packers increasingly load payloads with malformed or missing PE headers to hinder analysis and detection.
- [ACBackdoor: Analysis of a New Multiplatform Backdoor](https://research.intezer.com/blog/2019/11/acbackdoor-analysis-of-a-new-multiplatform-backdoor/) (2019-11-18): ACBackdoor is an undocumented backdoor with Linux and Windows variants sharing one C2 protocol; the Windows variant was delivered via Fallout Exploit Kit.
- [PureLocker: New Ransomware-as-a-Service Being Used in Targeted Attacks Against Servers](https://research.intezer.com/blog/2019/11/purelocker-ransomware-being-used-in-targeted-attacks-against-servers/) (2019-11-12): PureLocker, ransomware written in PureBasic and used in targeted attacks on servers, shares code with the more_eggs backdoor sold by a MaaS provider.
- [Prince of Persia: The Sands of Foudre](https://research.intezer.com/blog/2018/08/prince-of-persia-the-sands-of-foudre/) (2018-08-17): Foudre version 8 shows the Prince of Persia (Infy) campaign, believed to be Iranian, is still active, using a protest video as a lure and an updated DGA.
- [Yet Another Distraction? A New Version of North Korean Ransomware Hermes Has Emerged](https://research.intezer.com/blog/2018/02/another-distraction-new-version-north-korean-ransomware-hermes/) (2018-02-08): Hermes 2.1 ransomware shares code with the Hermes version used as a diversion in a Taiwan bank heist and thought to originate from North Korea’s Lazarus group.
- [Don’t Be Fooled By Malware Signed with Stolen Certificates](https://research.intezer.com/blog/2017/12/dont-fooled-malware-signed-stolen-certificates-intezer-analyze-detects-major-breaches-security/) (2017-12-07): Malware signed with stolen certificates, like Stuxnet and the CCleaner backdoor, bypasses tools that trust signatures. Code reuse analysis checks code instead.
- [IcedID Banking Trojan Shares Code with Pony 2.0 Trojan](https://research.intezer.com/blog/2017/11/icedid-banking-trojan-shares-code-pony-2-0-trojan/) (2017-11-13): The IcedID banking trojan payload reuses code from Pony 2.0, mostly functions for stealing email credentials such as Outlook’s GrabOutlook routine.
- [NotPetya Returns as Bad Rabbit](https://research.intezer.com/blog/2017/10/notpetya-returns-bad-rabbit/) (2017-10-25): Bad Rabbit ransomware reuses NotPetya code: 27% of its fake Adobe Flash installer loader and 13% of its encryption module match NotPetya samples.
- [Evidence Aurora Operation Still Active Part 2: More Ties Uncovered Between CCleaner Hack & Chinese Hackers](https://research.intezer.com/blog/2017/10/evidence-aurora-operation-still-active-part-2-more-ties-uncovered-between-ccleaner-hack-chinese-hackers/) (2017-10-02): Code shared by the CCleaner stage 2 payload and APT17 samples strengthens the link to the Axiom group, in an attack we assess was most likely state-sponsored.
- [Evidence Aurora Operation Still Active: Supply Chain Attack Through CCleaner](https://research.intezer.com/blog/2017/09/evidence-aurora-operation-still-active-supply-chain-attack-through-ccleaner/) (2017-09-20): A unique base64 function shared by the CCleaner 5.33 backdoor and earlier APT17 samples suggests the Operation Aurora group was still active in 2017.
