## Posts

- [When Everything Becomes Open-Source](https://research.intezer.com/blog/2026/11/when-everything-becomes-open-source/) (2026-11-10): AI agents rebuilt maintainable source code for Slack, Apple’s Finder and the TinyTurla-NG backdoor from binaries alone. Compiled code no longer hides source.
- [Lightning Framework: New Undetected "Swiss Army Knife" Linux Malware ⚡](https://research.intezer.com/blog/2022/07/lightning-framework-new-linux-threat/) (2022-07-21): Lightning Framework is a previously undetected modular Linux malware with a downloader, core module and plugins. It can install rootkits and open SSH.
- [OrBit: New Undetected Linux Threat Uses Unique Hijack of Execution Flow](https://research.intezer.com/blog/2022/07/orbit-new-undetected-linux-threat/) (2022-07-06): OrBit is an undetected Linux threat that hijacks the dynamic loader to infect every process, hooking functions to hide, steal credentials and give SSH access.
- [Symbiote Deep-Dive: Analysis of a New, Nearly-Impossible-to-Detect Linux Threat](https://research.intezer.com/blog/2022/06/new-linux-threat-symbiote/) (2022-06-09): Symbiote is a Linux malware loaded into every running process via LD_PRELOAD. It hides files, processes and traffic using BPF hooking and harvests credentials.
- [Detection Rules for Sysjoker (and How to Make Them With Osquery)](https://research.intezer.com/blog/2022/01/detection-rules-for-sysjoker-and-how-to-make-them-with-osquery/) (2022-01-14): Osquery queries for hunting SysJoker on Linux, macOS and Windows, built from its file artifacts and persistence and packaged as a ready-to-use query pack.
- [New SysJoker Backdoor Targets Windows, Linux, and macOS](https://research.intezer.com/blog/2022/01/new-backdoor-sysjoker/) (2022-01-11): SysJoker is a multi-platform backdoor for Windows, macOS and Linux, found on a Linux web server at an educational institution. Analysis, IoCs and detections.
- [New Linux Backdoor RedXOR Likely Operated by Chinese Nation-State Actor](https://research.intezer.com/blog/2021/03/new-linux-backdoor-redxor-likely-operated-by-chinese-nation-state-actor/) (2021-03-10): RedXOR, a Linux backdoor posing as polkit daemon, shares traits with Winnti-linked PWNLNX and XOR.DDOS and is likely operated by a Chinese nation-state actor.
- [Watch Your Containers: Doki Infecting Docker Servers in the Cloud](https://research.intezer.com/blog/2020/07/watch-your-containers-doki-infecting-docker-servers-in-the-cloud/) (2020-07-28): Doki, an undetected Linux backdoor used by the Ngrok Mining Botnet, infects exposed Docker API servers and generates C&C domains from the Dogecoin blockchain.
- [Linux Rekoobe Operating with New, Undetected Malware Samples](https://research.intezer.com/blog/2020/01/linux-rekoobe-operating-with-new-undetected-malware-samples/) (2020-01-20): New statically compiled variants of Rekoobe, a Linux trojan first reported in 2015, evade detection after its authors stripped attributive strings.
- [ChinaZ Updates Toolkit by Introducing New, Undetected Malware](https://research.intezer.com/blog/2019/12/chinaz-updates-toolkit-by-introducing-new-undetected-malware/) (2019-12-13): ChinaZ is using new low-detection Linux malware, NewManager, AmpManager and DDoSManager, which combine backdoor and DDoS bot capabilities.
- [ACBackdoor: Analysis of a New Multiplatform Backdoor](https://research.intezer.com/blog/2019/11/acbackdoor-analysis-of-a-new-multiplatform-backdoor/) (2019-11-18): ACBackdoor is an undocumented backdoor with Linux and Windows variants sharing one C2 protocol; the Windows variant was delivered via Fallout Exploit Kit.
- [APT37: Final1stspy Reaping the FreeMilk](https://research.intezer.com/blog/2018/10/apt37-final1stspy-reaping-the-freemilk/) (2018-10-03): An earlier Final1stspy DLL shares unique code with ROKRAT from the FreeMilk campaign, adding evidence that links NOKKI and Final1stspy to APT37 (Group123).
- [IcedID Banking Trojan Shares Code with Pony 2.0 Trojan](https://research.intezer.com/blog/2017/11/icedid-banking-trojan-shares-code-pony-2-0-trojan/) (2017-11-13): The IcedID banking trojan payload reuses code from Pony 2.0, mostly functions for stealing email credentials such as Outlook’s GrabOutlook routine.
- [Silence of the Moles](https://research.intezer.com/blog/2017/11/silenceofthemoles/) (2017-11-01): The loader of Silence, malware aimed at financial institutions, shares unique code with the Mole ransomware loader, a possible sign of the same threat actor.
- [Evidence Aurora Operation Still Active Part 2: More Ties Uncovered Between CCleaner Hack & Chinese Hackers](https://research.intezer.com/blog/2017/10/evidence-aurora-operation-still-active-part-2-more-ties-uncovered-between-ccleaner-hack-chinese-hackers/) (2017-10-02): Code shared by the CCleaner stage 2 payload and APT17 samples strengthens the link to the Axiom group, in an attack we assess was most likely state-sponsored.
- [Evidence Aurora Operation Still Active: Supply Chain Attack Through CCleaner](https://research.intezer.com/blog/2017/09/evidence-aurora-operation-still-active-supply-chain-attack-through-ccleaner/) (2017-09-20): A unique base64 function shared by the CCleaner 5.33 backdoor and earlier APT17 samples suggests the Operation Aurora group was still active in 2017.
- [New Variants of Agent.BTZ/ComRAT Found: The Threat That Hit The Pentagon In 2008 Still Evolving; Part 2/2](https://research.intezer.com/blog/2017/09/new-variants-of-agent-btz-comrat-found-part-2/) (2017-09-13): How we hunted new Agent.BTZ/ComRAT variants: filtering out library code, isolating unique functions kept since 2007 and turning them into YARA rules.
- [New Variants of Agent.BTZ/ComRAT Found: The Threat That Hit The Pentagon In 2008 Still Evolving; Part 1/2](https://research.intezer.com/blog/2017/08/new-variants-of-agent-btz-comrat-found/) (2017-08-07): New Agent.BTZ/ComRAT variants from the Turla group: about a dozen new samples and over 70 unknown IPs and domains abusing satellite internet providers.
