## Posts

- [OrBit (Re)turns: Tracking an Open-Source Linux Rootkit Across Four Years of Forks and Deployments](https://research.intezer.com/blog/2026/05/orbit-returns/) (2026-05-14): OrBit is a fork of the Medusa open-source LD_PRELOAD rootkit. Samples from 2022 to 2026 show two lineages with rotating keys, credentials and evasion hooks.
- [Threat Bulletin: Fire in the Woods – A New Variant of FireWood](https://research.intezer.com/blog/2025/08/threat-bulletin-firewood/) (2025-08-13): A new, low-detected variant of FireWood, a Linux backdoor of the Project Wood lineage, keeps its core functions but changes implementation and configuration.
- [Detection Rules for Lightning Framework (and How to Make Them With Osquery)](https://research.intezer.com/blog/2022/08/lightning-framework-linux-detection-rules-osquery/) (2022-08-03): Osquery queries for detecting Lightning Framework on Linux, covering its file artifacts, persistence and rootkits, packaged as a ready-to-use query pack.
- [Lightning Framework: New Undetected "Swiss Army Knife" Linux Malware ⚡](https://research.intezer.com/blog/2022/07/lightning-framework-new-linux-threat/) (2022-07-21): Lightning Framework is a previously undetected modular Linux malware with a downloader, core module and plugins. It can install rootkits and open SSH.
- [OrBit: New Undetected Linux Threat Uses Unique Hijack of Execution Flow](https://research.intezer.com/blog/2022/07/orbit-new-undetected-linux-threat/) (2022-07-06): OrBit is an undetected Linux threat that hijacks the dynamic loader to infect every process, hooking functions to hide, steal credentials and give SSH access.
- [Symbiote Deep-Dive: Analysis of a New, Nearly-Impossible-to-Detect Linux Threat](https://research.intezer.com/blog/2022/06/new-linux-threat-symbiote/) (2022-06-09): Symbiote is a Linux malware loaded into every running process via LD_PRELOAD. It hides files, processes and traffic using BPF hooking and harvests credentials.
- [TeamTNT Cryptomining Explosion 🧨](https://research.intezer.com/blog/2022/02/teamtnt-cryptomining-explosion/) (2022-02-18): TeamTNT’s cryptojacking campaigns from October 2019 through 2021, moving from Redis to Docker and Kubernetes, with their tooling, timeline, TTPs and IOCs.
- [New SysJoker Backdoor Targets Windows, Linux, and macOS](https://research.intezer.com/blog/2022/01/new-backdoor-sysjoker/) (2022-01-11): SysJoker is a multi-platform backdoor for Windows, macOS and Linux, found on a Linux web server at an educational institution. Analysis, IoCs and detections.
- [Conducting Digital Forensics Incident Response (DFIR) on an Infected GitLab Server](https://research.intezer.com/blog/2021/11/dfir-infected-gitlab-server/) (2021-11-04): Runtime alerts on a GitLab server exposed Metasploit shellcode and an XMRig miner in a container, likely entering via weak credentials or CVE-2021-22205.
- [Vermilion Strike: Linux and Windows Re-implementation of Cobalt Strike](https://research.intezer.com/blog/2021/09/vermilionstrike-reimplementation-cobaltstrike/) (2021-09-13): Vermilion Strike is an undetected Linux re-implementation of Cobalt Strike Beacon, with matching Windows samples, used against telecom, government and finance.
- [HabitsRAT Used to Target Linux and Windows Servers](https://research.intezer.com/blog/2021/04/habitsrat-used-to-target-linux-and-windows-servers/) (2021-04-20): HabitsRAT, a Go RAT first seen on hacked Microsoft Exchange servers, has an undetected Linux variant and runs only commands signed with the attacker’s key.
- [Rocke Group Actively Targeting the Cloud: Wants Your SSH Keys](https://research.intezer.com/blog/2021/04/rocke-group-actively-targeting-the-cloud-wants-your-ssh-keys/) (2021-04-06): A new Rocke Group variant spreads via saved SSH keys, weak passwords and Jenkins, Redis and ActiveMQ flaws to run a Monero miner on cloud servers.
- [Early Bird Catches the Worm: New Golang Worm Drops XMRig Miner on Servers](https://research.intezer.com/blog/2020/12/new-golang-worm-drops-xmrig-miner-on-servers/) (2020-12-29): An undetected Golang worm spreads to Windows and Linux servers via weak MySQL, Tomcat and Jenkins passwords and WebLogic CVE-2020-14882 to run XMRig.
- [Stantinko's Proxy After Your Apache Server](https://research.intezer.com/blog/2020/11/stantinkos-proxy-after-your-apache-server/) (2020-11-24): A new version of Stantinko’s Linux proxy trojan masquerades as Apache httpd. We analyze version 2.17 and compare it with version 1.2, documented by ESET.
- [A Storm is Brewing: IPStorm Now Has Linux Malware](https://research.intezer.com/blog/2020/10/a-storm-is-brewing-ipstorm-now-has-linux-malware/) (2020-10-01): IPStorm, a Golang botnet that hides traffic in the IPFS peer-to-peer network, now has Linux variants adding SSH brute forcing, Steam gaming fraud and ad fraud.
- [Watch Your Containers: Doki Infecting Docker Servers in the Cloud](https://research.intezer.com/blog/2020/07/watch-your-containers-doki-infecting-docker-servers-in-the-cloud/) (2020-07-28): Doki, an undetected Linux backdoor used by the Ngrok Mining Botnet, infects exposed Docker API servers and generates C&C domains from the Dogecoin blockchain.
- [Kaiji: New Chinese Linux malware turning to Golang](https://research.intezer.com/blog/2020/05/kaiji-new-chinese-linux-malware-turning-to-golang/) (2020-05-04): Kaiji is a custom Golang botnet of Chinese origin that brute-forces root SSH logins on Linux servers and IoT devices to launch DDoS attacks.
- [Fantastic payloads and where we find them](https://research.intezer.com/blog/2020/03/fantastic-payloads-and-where-we-find-them/) (2020-03-30): Emotet, Dridex, Ursnif and TrickBot packers increasingly load payloads with malformed or missing PE headers to hinder analysis and detection.
- [Linux Rekoobe Operating with New, Undetected Malware Samples](https://research.intezer.com/blog/2020/01/linux-rekoobe-operating-with-new-undetected-malware-samples/) (2020-01-20): New statically compiled variants of Rekoobe, a Linux trojan first reported in 2015, evade detection after its authors stripped attributive strings.
- [ACBackdoor: Analysis of a New Multiplatform Backdoor](https://research.intezer.com/blog/2019/11/acbackdoor-analysis-of-a-new-multiplatform-backdoor/) (2019-11-18): ACBackdoor is an undocumented backdoor with Linux and Windows variants sharing one C2 protocol; the Windows variant was delivered via Fallout Exploit Kit.
- [PureLocker: New Ransomware-as-a-Service Being Used in Targeted Attacks Against Servers](https://research.intezer.com/blog/2019/11/purelocker-ransomware-being-used-in-targeted-attacks-against-servers/) (2019-11-12): PureLocker, ransomware written in PureBasic and used in targeted attacks on servers, shares code with the more_eggs backdoor sold by a MaaS provider.
- [Russian Cybercrime Group FullofDeep Behind QNAPCrypt Ransomware Campaigns](https://research.intezer.com/blog/2019/09/russian-cybercrime-group-fullofdeep-behind-qnapcrypt-ransomware-campaigns/) (2019-09-20): A new QNAPCrypt sample shares code and encryption with the 15 campaigns we halted in July. Its ransom note and strings point to Russian group FullofDeep.
- [Watching the WatchBog: New BlueKeep Scanner and Linux Exploits](https://research.intezer.com/blog/2019/07/watching-the-watchbog-new-bluekeep-scanner-and-linux-exploits/) (2019-07-24): A new WatchBog cryptomining botnet version hit an estimated 4,500 Linux machines, adding fresh Jira, Exim and Solr exploits and a BlueKeep RDP scanner.
- [EvilGnome: Rare Malware Spying on Linux Desktop Users](https://research.intezer.com/blog/2019/07/evilgnome-rare-malware-spying-on-linux-desktop-users/) (2019-07-17): EvilGnome is an undetected Linux backdoor posing as a Gnome shell extension that takes screenshots, records audio and steals files. Linked to Gamaredon Group.
- [How We Seized 15 Active Ransomware Campaigns Targeting Linux File Storage Servers](https://research.intezer.com/blog/2019/07/seizing-15-active-ransomware-campaigns-targeting-linux-file-storage-servers/) (2019-07-10): We simulated over 1,091 infections to exhaust QNAPCrypt’s static Bitcoin wallet list, temporarily halting 15 ransomware campaigns targeting QNAP NAS servers.
- [HiddenWasp Malware Stings Targeted Linux Systems](https://research.intezer.com/blog/2019/05/hiddenwasp-malware-targeting-linux-systems/) (2019-05-29): HiddenWasp is a Linux trojan with a rootkit, undetected at discovery, used for targeted remote control and reusing code from Mirai and the Azazel rootkit.
- [Technical Analysis: Pacha Group Competing against Rocke Group for Cryptocurrency Mining Foothold on the Cloud](https://research.intezer.com/blog/2019/05/technical-analysis-cryptocurrency-mining-war-on-the-cloud/) (2019-05-09): New Linux.GreedyAntd variants show Pacha Group targeting cloud environments and using blacklists to remove Rocke Group miners and cloud security agents.
- [Technical Analysis: Pacha Group Deploying Undetected Cryptojacking Campaigns on Linux Servers](https://research.intezer.com/blog/2019/02/technical-analysis-pacha-group/) (2019-02-28): Pacha Group, likely of Chinese origin, runs undetected Linux.GreedyAntd cryptojacking campaigns whose IPC-linked multi-stage design evades dynamic analysis.
- [ChinaZ Revelations: Revealing ChinaZ Relationships with other Chinese Threat Actor Groups](https://research.intezer.com/blog/2019/01/chinaz-relations/) (2019-01-07): We tracked the ChinaZ DDoS group through honeypot hits and its file servers, and found possible connections to Nitol, MrBlack and ServStart actors.

- ["EternalMiner" Copycats exploiting SambaCry for cryptocurrency mining](https://research.intezer.com/blog/2017/07/eternalminer-copycats/) (2017-07-26): CopyMiner: copycats exploiting the SambaCry Samba vulnerability to install a cryptominer and the Tsunami backdoor, with daily updates from backup servers.
