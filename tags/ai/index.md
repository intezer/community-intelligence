## Posts

- [When Everything Becomes Open-Source](https://research.intezer.com/blog/2026/11/when-everything-becomes-open-source/) (2026-11-10): AI agents rebuilt maintainable source code for Slack, Apple’s Finder and the TinyTurla-NG backdoor from binaries alone. Compiled code no longer hides source.
- [When the Whole Company Adopts AI: What It Does to Your SOC](https://research.intezer.com/blog/2026/08/when-the-whole-company-adopts-ai/) (2026-08-25): Intezer platform data shows AI-related alerts are a small but fast-growing share of SOC alerts, mostly false alarms that bury the genuine AI exposures.
- [When the AI Edits Its Own Trust Boundary: Remote Code Execution Vulnerability in AWS's Agentic IDE](https://research.intezer.com/blog/2026/07/remote-code-execution-kiro/) (2026-07-20): A remote code execution flaw in Kiro, AWS’s agentic IDE: hidden instructions in a web page make it rewrite its MCP config and run code. AWS has patched it.
- [How attackers are gaining access to LLM inference](https://research.intezer.com/blog/2026/06/how-attackers-access-llm-inference/) (2026-06-03): Five routes attackers use to reach LLM inference without paying: offensive LLMs, crypto payment, free-tier APIs, leaked API keys and exposed LLM servers.
