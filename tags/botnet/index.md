## Posts

- [Stantinko's Proxy After Your Apache Server](https://research.intezer.com/blog/2020/11/stantinkos-proxy-after-your-apache-server/) (2020-11-24): A new version of Stantinko’s Linux proxy trojan masquerades as Apache httpd. We analyze version 2.17 and compare it with version 1.2, documented by ESET.
- [A Storm is Brewing: IPStorm Now Has Linux Malware](https://research.intezer.com/blog/2020/10/a-storm-is-brewing-ipstorm-now-has-linux-malware/) (2020-10-01): IPStorm, a Golang botnet that hides traffic in the IPFS peer-to-peer network, now has Linux variants adding SSH brute forcing, Steam gaming fraud and ad fraud.
- [Kaiji: New Chinese Linux malware turning to Golang](https://research.intezer.com/blog/2020/05/kaiji-new-chinese-linux-malware-turning-to-golang/) (2020-05-04): Kaiji is a custom Golang botnet of Chinese origin that brute-forces root SSH logins on Linux servers and IoT devices to launch DDoS attacks.
- [HiddenWasp Malware Stings Targeted Linux Systems](https://research.intezer.com/blog/2019/05/hiddenwasp-malware-targeting-linux-systems/) (2019-05-29): HiddenWasp is a Linux trojan with a rootkit, undetected at discovery, used for targeted remote control and reusing code from Mirai and the Azazel rootkit.
- [Technical Analysis: Pacha Group Deploying Undetected Cryptojacking Campaigns on Linux Servers](https://research.intezer.com/blog/2019/02/technical-analysis-pacha-group/) (2019-02-28): Pacha Group, likely of Chinese origin, runs undetected Linux.GreedyAntd cryptojacking campaigns whose IPC-linked multi-stage design evades dynamic analysis.
- [ChinaZ Revelations: Revealing ChinaZ Relationships with other Chinese Threat Actor Groups](https://research.intezer.com/blog/2019/01/chinaz-relations/) (2019-01-07): We tracked the ChinaZ DDoS group through honeypot hits and its file servers, and found possible connections to Nitol, MrBlack and ServStart actors.
- [Muhstik Botnet Reloaded: New Variants Targeting phpMyAdmin Servers](https://research.intezer.com/blog/2018/11/muhstik-botnet-reloaded-new-variants-targeting-phpmyadmin-servers/) (2018-11-12): New Muhstik botnet variants add a scanner module targeting phpMyAdmin web servers, with code likely borrowed and modified from the open-source Pnscan tool.
