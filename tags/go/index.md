## Posts

- [Elephant Framework Delivered in Phishing Attacks Against Ukrainian Organizations](https://research.intezer.com/blog/2022/04/elephant-malware-targeting-ukrainian-orgs/) (2022-04-04): Elephant, a Go malware framework that includes GrimPlant and GraphSteel, is delivered by spear phishing from spoofed Ukrainian government email addresses.
- [All Your Go Binaries are Belong to Us](https://research.intezer.com/blog/2021/12/all-your-go-binaries-are-belong-to-us/) (2021-12-02): How to extract hidden metadata from stripped Go binaries using the standard library: build info, dependency versions for vulnerability checks, and source maps.
- [New Type of Supply Chain Attack Could Put Popular Admin Tools at Risk](https://research.intezer.com/blog/2021/11/chainjacking-supply-chain-attack-puts-popular-admin-tools-at-risk/) (2021-11-16): ChainJacking, found with Checkmarx, abuses GitHub username changes to hijack Go packages fetched from repositories, which could put popular admin tools at risk.
