## Posts

- [Exposed Prefect Workflows Could Lead to Disruptive Attacks](https://research.intezer.com/blog/2021/10/exposed-prefect-workflows-could-lead-to-disruptive-attacks/) (2021-10-26): Hundreds of misconfigured Prefect workflow servers are exposed online, which could let attackers modify or delete workflows, tasks, agents and execution logs.
- [Misconfigured Airflows Leak Thousands of Credentials from Popular Services](https://research.intezer.com/blog/2021/10/misconfigured-airflows-leak-credentials/) (2021-10-04): Misconfigured Apache Airflow instances exposed credentials for services such as Slack, PayPal and AWS through variables, connections, logs and config files.
- [Guide to Digital Forensics Incident Response in the Cloud](https://research.intezer.com/blog/2021/08/guide-to-digital-forensics-incident-response-in-the-cloud/) (2021-08-11): How cloud incident response differs from on-premises forensics, from evidence collection to CSP limits, and how to prepare for, detect and contain attacks.
- [New Attacks on Kubernetes via Misconfigured Argo Workflows](https://research.intezer.com/blog/2021/07/new-attacks-on-kubernetes-via-misconfigured-argo-workflows/) (2021-07-20): Misconfigured Argo Workflows instances let attackers run unauthorized code on Kubernetes clusters. We found operators already using them to drop cryptominers.
- [Why Relying on the Cloud Provider for Security is Not Enough](https://research.intezer.com/blog/2021/05/why-relying-on-the-cloud-provider-for-security-is-not-enough/) (2021-05-20): Cloud Snooper, flaws in security tools, misconfigurations and unauthorized workload access show where the built-in security of AWS, Azure and GCP falls short.
- [Attackers Abusing Legitimate Cloud Monitoring Tools to Conduct Cyber Attacks](https://research.intezer.com/blog/2020/09/attackers-abusing-legitimate-cloud-monitoring-tools-to-conduct-cyber-attacks/) (2020-09-08): TeamTNT installs Weave Scope, a legitimate monitoring tool, on victims’ Docker and Kubernetes hosts to map the environment and run commands without malware.
- [Watch Your Containers: Doki Infecting Docker Servers in the Cloud](https://research.intezer.com/blog/2020/07/watch-your-containers-doki-infecting-docker-servers-in-the-cloud/) (2020-07-28): Doki, an undetected Linux backdoor used by the Ngrok Mining Botnet, infects exposed Docker API servers and generates C&C domains from the Dogecoin blockchain.
- [Technical Analysis: Pacha Group Competing against Rocke Group for Cryptocurrency Mining Foothold on the Cloud](https://research.intezer.com/blog/2019/05/technical-analysis-cryptocurrency-mining-war-on-the-cloud/) (2019-05-09): New Linux.GreedyAntd variants show Pacha Group targeting cloud environments and using blacklists to remove Rocke Group miners and cloud security agents.
