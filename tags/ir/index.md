## Posts

- [Boost Your SOC Skills: How to Detect Good Apps Gone Bad](https://research.intezer.com/blog/2022/03/boost-your-soc-skills-how-to-detect-good-apps-gone-bad/) (2022-03-01): How attackers abuse trusted Windows tools such as PsExec, MSHTA, Squiblydoo and WMI, with real attack examples and detection rules SOC analysts can adapt.
- [3 Ways to Save Incident Response Time](https://research.intezer.com/blog/2022/01/save-incident-response-time-intezer-analyze/) (2022-01-31): Three ways to cut incident response time: classify files collected from disk images, analyze memory dumps and scan live endpoints for threats loaded in memory.
- [Conducting Digital Forensics Incident Response (DFIR) on an Infected GitLab Server](https://research.intezer.com/blog/2021/11/dfir-infected-gitlab-server/) (2021-11-04): Runtime alerts on a GitLab server exposed Metasploit shellcode and an XMRig miner in a container, likely entering via weak credentials or CVE-2021-22205.
- [Guide to Digital Forensics Incident Response in the Cloud](https://research.intezer.com/blog/2021/08/guide-to-digital-forensics-incident-response-in-the-cloud/) (2021-08-11): How cloud incident response differs from on-premises forensics, from evidence collection to CSP limits, and how to prepare for, detect and contain attacks.
- [Building Your Bullet Proof Incident Response Plan](https://research.intezer.com/blog/2018/03/building-your-bullet-proof-incident-response-plan/) (2018-03-15): An incident response plan depends on finding real malware among false positives. Code reuse detection helps SOC teams classify threats and remediate sooner.
