## Posts

- [Detection Rules for Lightning Framework (and How to Make Them With Osquery)](https://research.intezer.com/blog/2022/08/lightning-framework-linux-detection-rules-osquery/) (2022-08-03): Osquery queries for detecting Lightning Framework on Linux, covering its file artifacts, persistence and rootkits, packaged as a ready-to-use query pack.
- [SOC Level Up: Threat Hunting and Detection With Sigma](https://research.intezer.com/blog/2022/05/threat-hunting-sigma-detection-rules/) (2022-05-17): How to use Sigma rules for threat hunting and detection, from hunting on behavior rather than indicators to writing Sigma detection rules for Emotet.
- [How to Write YARA Rules That Minimize False Positives](https://research.intezer.com/blog/2022/05/yara-rules-minimize-false-positives/) (2022-05-12): How code reuse between malicious files can generate YARA rules automatically with fewer false positives, with example rules for Emotet and a WannaCry variant.
- [SOC Level Up: Introduction to Sigma Rules](https://research.intezer.com/blog/2022/03/intro-to-sigma-rules/) (2022-03-22): An introduction to Sigma rules for SOC analysts: what they are, how the metadata, log source and detection sections work, and how to compile them for your SIEM.
- [Radare Plugin is Here for Intezer Community](https://research.intezer.com/blog/2022/02/radare-plugin-automate-reverse-engineering/) (2022-02-08): The r2analyze community plugin brings Intezer code genomics into Radare2, so reverse engineers can attribute a sample to a malware family or threat actor.
- [Make your First Malware Honeypot in Under 20 Minutes](https://research.intezer.com/blog/2022/01/how-to-make-malware-honeypot/) (2022-01-20): Set up a malware honeypot in the cloud with open-source software in under 20 minutes and analyze the attacks it catches, plus the IoCs our honeypot collected.
- [Detection Rules for Sysjoker (and How to Make Them With Osquery)](https://research.intezer.com/blog/2022/01/detection-rules-for-sysjoker-and-how-to-make-them-with-osquery/) (2022-01-14): Osquery queries for hunting SysJoker on Linux, macOS and Windows, built from its file artifacts and persistence and packaged as a ready-to-use query pack.
- [Teaching Capa New Tricks: Analyzing Capabilities in PE and ELF Files](https://research.intezer.com/blog/2021/09/analyzing-capabilities-in-pe-and-elf-files/) (2021-09-15): Intezer extended FireEye’s capa to analyze ELF files and added Linux rules. Pairing extracted capabilities with code reuse helps connect malware families.
- [MoP – "Master of Puppets" – Advanced malware tracking framework revealed at BlackHat Arsenal 2019](https://research.intezer.com/blog/2019/08/mop-master-of-puppets-advanced-malware-tracking-framework-revealed-at-blackhat-arsenal-2019/) (2019-08-14): MoP (Master of Puppets) is an open-source Python framework for building malware trackers that simulate infected workstations to interact with C2 servers.
