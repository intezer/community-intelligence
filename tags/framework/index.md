## Posts

- [Technical Analysis of a Novel IMEEX Framework](https://research.intezer.com/blog/2024/10/technical-analysis-of-a-novel-imeex-framework/) (2024-10-10): IMEEX is a custom Windows DLL framework seen targeting Djibouti and Afghanistan, with remote control features and signs of infrastructure reuse with ShadowPad.
- [Detection Rules for Lightning Framework (and How to Make Them With Osquery)](https://research.intezer.com/blog/2022/08/lightning-framework-linux-detection-rules-osquery/) (2022-08-03): Osquery queries for detecting Lightning Framework on Linux, covering its file artifacts, persistence and rootkits, packaged as a ready-to-use query pack.
- [Lightning Framework: New Undetected "Swiss Army Knife" Linux Malware ⚡](https://research.intezer.com/blog/2022/07/lightning-framework-new-linux-threat/) (2022-07-21): Lightning Framework is a previously undetected modular Linux malware with a downloader, core module and plugins. It can install rootkits and open SSH.
- [Elephant Framework Delivered in Phishing Attacks Against Ukrainian Organizations](https://research.intezer.com/blog/2022/04/elephant-malware-targeting-ukrainian-orgs/) (2022-04-04): Elephant, a Go malware framework that includes GrimPlant and GraphSteel, is delivered by spear phishing from spoofed Ukrainian government email addresses.
- [Vermilion Strike: Linux and Windows Re-implementation of Cobalt Strike](https://research.intezer.com/blog/2021/09/vermilionstrike-reimplementation-cobaltstrike/) (2021-09-13): Vermilion Strike is an undetected Linux re-implementation of Cobalt Strike Beacon, with matching Windows samples, used against telecom, government and finance.
- [How to Detect Cobalt Strike](https://research.intezer.com/blog/2021/08/cobalt-strike-detect-this-persistent-threat/) (2021-08-18): Cobalt Strike Beacon arrives via Office macros, supply chain attacks, living off the land and EXE files. How to detect each with static and dynamic analysis.
- [VB2020 - Advanced Pasta Threat: Mapping Malware Use of Open Source Offensive Security Tools](https://research.intezer.com/blog/2020/09/advanced-pasta-threat-mapping-malware-use-of-open-source-offensive-security-tools/) (2020-09-30): VB2020 research mapping threat actor use of open source offensive security tools through code reuse, and how those libraries enable code-based YARA signatures.
- [MoP – "Master of Puppets" – Advanced malware tracking framework revealed at BlackHat Arsenal 2019](https://research.intezer.com/blog/2019/08/mop-master-of-puppets-advanced-malware-tracking-framework-revealed-at-blackhat-arsenal-2019/) (2019-08-14): MoP (Master of Puppets) is an open-source Python framework for building malware trackers that simulate infected workstations to interact with C2 servers.
